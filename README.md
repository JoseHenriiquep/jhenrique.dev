# jhenrique.dev

Portfólio pessoal de José Henrique, construído como uma landing page React
estática com Vite.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build e validação

```bash
npm run build
npm test
npm run lint
npx tsc --noEmit
```

O build final é gerado em `dist/`, que é o diretório publicado pela Vercel.
